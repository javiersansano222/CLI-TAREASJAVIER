3. PRUEBAS REALES CONTRA EL SERVIDOR DEL CENTRO
------------------------------------------------

Solo en la red del instituto. Primero siempre `--simular`:

    uv run tareas comprobar-ia
    uv run tareas ejecutar resumir-apuntes ~/pruebas-tareas/Apuntes --simular
    uv run tareas ejecutar renombrar-apuntes ~/pruebas-tareas/Apuntes --simular
    uv run tareas ejecutar clasificar-apuntes ~/pruebas-tareas/Apuntes --simular

Luego, con calma y sobre COPIAS de pruebas:

    uv run tareas ejecutar resumir-apuntes ~/pruebas-tareas/Apuntes
    uv run tareas ejecutar renombrar-apuntes ~/pruebas-tareas/Apuntes
    uv run tareas ejecutar clasificar-apuntes ~/pruebas-tareas/Apuntes

Comprueba:
  - El `.resumen.md` se crea en `~/pruebas-tareas/Resúmenes` y termina
    con la viñeta «Para el examen:».
  - El renombrado cambia solo la base del nombre y conserva `.txt`/`.md`.
  - La clasificación crea `~/pruebas-tareas/Clasificados/<asignatura>/`.
  - Los tokens y segundos aparecen en la columna Detalle.
  - Ningún mensaje enseña `CENTRO_IA_KEY`.

Si el certificado del centro da error de validación, copia
`ca-simarro.crt` a `~/.config/opencode/ca-simarro.crt` o usa
`IA_TLS_VERIFICAR=0` SOLO dentro de la red del instituto.
